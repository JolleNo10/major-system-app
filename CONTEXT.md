# World Countries glossary

- **Setup** — The contextual structural workspace for geography order,
  inspection, and mnemonic authoring. It does not start an activity.
- **Drill** — A recall-strengthening purpose with the three Drill modes and
  durable Drill evidence according to each mode's rules.
- **Learning** — A Learn & Practise category whose named activities may write
  their defined durable learning milestone.
- **Practice** — A Learn & Practise category for transient rehearsal. Practice
  does not write durable evidence, milestones, proficiency, or preferences.
- **Learning Readiness** — The derived three-state view: Not learned,
  Countries learned, or Countries + Capitals learned.
- **Purpose** — The selected activity intent: Drill or Learn & Practise.
- **Mode** — The concrete activity within a purpose or category.
- **Due review** — System-directed maintenance work selected from due review
  candidates, separate from the user's activity purpose.
